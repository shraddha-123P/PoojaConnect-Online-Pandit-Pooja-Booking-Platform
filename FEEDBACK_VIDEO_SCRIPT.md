# PujaConnect - Feedback Video Script

Use this for a two-to-three-minute project walkthrough and reflection.

## Opening

Hello, my project is PujaConnect, an online Pandit and puja booking platform. The goal is to help users find verified Pandits, understand ritual requirements and pricing, and submit organized booking requests.

## Problem and Solution

Traditionally, users depend on personal references, phone calls, or temple visits. This makes it difficult to compare Pandits, confirm availability, understand costs, and avoid scheduling problems. PujaConnect brings discovery, ritual details, booking, Pandit responses, and admin verification into one responsive web experience.

## Product Walkthrough

First, I can filter Pandits by city and ritual type. Each profile shows verification status, experience, languages, supported rituals, pricing, and availability.

Next, I can choose a ritual, Pandit, date, time slot, and service location. The booking request is added to booking history with a pending status.

The Pandit desk shows incoming requests. A Pandit can accept or reject a request, and the status is reflected in the user experience.

The admin dashboard provides a provider approval queue and booking metrics. This demonstrates how the platform can support trust, moderation, and operational visibility.

## Learnings

The main learning was that a service platform needs more than a listing page. The complete experience must connect discovery, transparent information, scheduling, provider actions, and administration. Availability conflicts, verification, and clear cultural information are important product concerns for this domain.

## Limitations and Next Steps

The current version is a frontend prototype with in-memory sample data. The next phase would add secure authentication, a backend API, persistent storage, availability locking, payments, notifications, and production deployment.

## Closing

PujaConnect is intended to make religious service discovery more organized, transparent, and accessible while giving Pandits a practical digital workflow. Thank you for reviewing the project.
